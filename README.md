# URL Shortener API

A REST API built with FastAPI and PostgreSQL to shorten URLs and track click analytics.

## Features
- Shorten long URLs
- Redirect to original URL via short code
- Track click count per URL
- Input validation with Pydantic
- PostgreSQL database with SQLAlchemy ORM

## Tech Stack
- FastAPI
- PostgreSQL
- SQLAlchemy
- Pydantic v2
- Uvicorn

## Setup

1. Clone the repo
2. Create virtual environment
